## Implementation Steps

### Prerequisites
1. **Start noVNC container** (if not running):
   ```bash
   docker run -d --name playwright-novnc --network host \
     -e SCREEN_WIDTH=1920 -e SCREEN_HEIGHT=1080 \
     -e MCP_BROWSER=chromium ghcr.io/xtr-dev/mcp-playwright-novnc
   ```

2. **Start editor dev environment** (if not running):
   ```bash
   docker compose up -d
   ```

3. **Verify editor accessible:**
   ```bash
   curl -s http://localhost:9888/ | head -5
   ```

### Test Execution (3PS)

**Driver sub-agent actions:**
1. Navigate to http://localhost:9888/ via `browser_navigate`
2. Execute test scenarios using MCP tools
3. Record test results

**Navigator sub-agent actions:**
1. Review each test executes correctly
2. Verify expected UI elements appear
3. Report pass/fail for each scenario

### Target Test Scenarios

**Onboarding & Auth (5 scenarios):**
1. View onboarding steps
2. Create account flow initiated
3. Successful authentication via URI
4. Authentication persists across sessions
5. Invalid token handling

**Settings Panel (5 scenarios):**
1. View OCC Credits card - unauthenticated
2. Sign in from settings
3. View OCC Credits card - authenticated
4. Sign out from settings
5. Balance fetch error

**Billing (Balance Polling - 5 scenarios):**
1. Initial balance display
2. Balance update after chat
3. Insufficient balance warning
4. Balance refresh on focus
5. Multiple deductions track correctly
